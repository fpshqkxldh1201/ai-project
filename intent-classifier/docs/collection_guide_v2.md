# v2 평가 문장 수집 가이드 (급우용 폼 + AI 보완)

v2 평가셋은 **내가 만든 문장이 아니라 다른 사람이 쓴 문장**으로 채웁니다. 같은 사람이 학습 문장과 평가 문장을 모두 쓰면 말투가 닮아 점수가 부풀기 때문입니다. 이 문서는 (1) 급우에게 보낼 안내문, (2) 폼 문항, (3) 수집 후 처리 순서를 담았습니다.

## 1. 목표 수량 (Phase 1에서 동결)
| 구분 | 최소 | 목표 | 비고 |
|---|---:|---:|---|
| IS (9개 의도) | 90 | 135 | 의도당 10~15 |
| OOS-far | 30 | 60 | O1~O4, O7 |
| OOS-near | 20 | 40 | O5, O6 + 의도 단어가 섞인 O1~O4, O7 |
| AMB(되묻기) | 20 | 40 | 모호·복합 |
| 합계 | 160 | 275 | 급우 문장이 부족한 부분만 AI가 보완, `source`에 표시 |

## 2. 급우에게 보낼 안내문 (복사해서 쓰세요)
> 안녕하세요! 인공지능 프로젝트에서 만든 음성 비서 'Lumi'가 사용자의 말을 얼마나 잘 알아듣는지 시험하려고 해요. **평소 비서에게 말하듯이** 문장을 5분만 써 주세요.
> - 이름·전화번호·학번 같은 개인정보는 쓰지 마세요(문장 안에도). 제출은 익명이에요.
> - 한국어든 영어든 편한 대로, 반말·존댓말·줄임말·오타 모두 괜찮아요.
> - 정답이 따로 없어요. 아래 상황 카드를 보고 떠오르는 대로 쓰면 돼요.
> - 쓴 문장은 평가 목적으로만 쓰고, 보고서에는 문장 일부가 예시로 실릴 수 있어요.

## 3. 폼 문항 (구글 폼, 약 12문항)
폼 첫 화면에 위 안내문과 "제출 내용은 익명 평가 자료로 쓰이는 것에 동의합니다" 체크박스를 둡니다.

**A. 의도 문장 (각 칸에 문장 2개씩, 필수 아님)**
1. 일정을 **새로 넣어** 달라고 할 때 (예: 약속·수업·회의)
2. **이미 있는 일정**이 뭔지 물어볼 때
3. **시간에 맞춰 알려** 달라고 할 때
4. **걸어 둔 알림·할 일**이 뭔지 물어볼 때
5. **나에 대해 기억**해 달라고 할 때
6. 기억해 둔 것을 **지워** 달라고 할 때
7. 궁금한 **정보·소식**을 찾아 달라고 할 때 (날씨·시세·뉴스 등)
8. **영상·음악**을 찾거나 틀어 달라고 할 때
9. 그냥 **기분·잡담**을 말할 때 (도구 이야기가 나와도 요청이 아닌 하소연이면 해당)

**B. 범위 밖 요청 (3칸 이상)**
10. 비서가 **못 할 것 같은 일**을 시켜 본다면? (문자 보내기, 주문, 기기 제어, 파일 정리, 설정 변경 등) 
11. 이미 잡은 일정·알림을 **고치거나 취소**하고 싶을 때
12. "**~하면 알려줘**"처럼 조건이 붙은 부탁

**C. 애매한 말 (2칸)**
13. 말을 짧게 줄여서 **무슨 뜻인지 되물어야 할 것 같은** 문장
14. 한 문장에 **부탁을 두 가지** 섞은 문장

**D. 메타 정보 (선택)**: 사용 언어 비율(한국어 위주/영어 위주/섞어서), 평소 쓰는 말투(반말/존댓말). 이름은 받지 않습니다.

## 4. 상황 카드 예시 (폼 상단에 이미지/텍스트로 첨부)
- 시험 기간인데 약속이 겹칠 것 같다 · 내일 아침 첫 수업에 늦으면 안 된다 · 친구 생일이 다음 주다 · 팀플 회의를 잡아야 한다 · 심심해서 노래를 듣고 싶다 · 엄마에게 연락해야 한다 · 영수증 정리하다 짜증이 났다 · 새 폰을 사려고 비교 중이다 · 룸메이트 이름을 비서가 알았으면 좋겠다 · 어제 한 말을 비서가 잊었으면 좋겠다

## 5. 수집 뒤 처리 순서
1. **정리**: 개인정보가 섞인 문장은 지우거나 일반화(이름 → "친구"). 빈 칸·중복 제거.
2. **라벨 후보**: 폼 문항 번호로 1차 라벨(문항 1→schedule_add …, 10~12→OOS 후보, 13~14→AMB 후보). 문항과 문장이 어긋나면 라벨 가이드로 다시 판단.
3. **AI 보완**: 최소 수량에 못 미치는 칸만 AI가 보완. 급우 문장의 말투를 참고하되 **베끼지 않음**. `source=ai`로 표시.
4. **이중 검토**: 두 사람(나 + 가능하면 급우 1명)이 라벨을 따로 붙이고, 다른 것만 모아 토론 → 라벨 가이드에 반영. 일치도(Cohen's κ)를 보고서에 기록.
5. **유사도 검사**: 학습/검증 문장과 자카드 ≥ 0.6이면 제외(`validate.py`가 경고).
6. **동결**: `test_v2_frozen.csv`로 저장하고 해시를 `results/frozen_v2.json`에 기록. 이후 수정 금지.

## 6. 해야 할 일과 예상 시간 (본인 기준)
| 일 | 시간 |
|---|---|
| 폼 만들기(위 문항 복붙) + 단톡/커뮤니티에 공유 | 30분 |
| 응답 정리·라벨 1차 검토 | 1~1.5시간 |
| AI 보완 문장 검토 | 30분 |
| 이중 검토 토론 | 30분 |

> 중간고사 주간(~10/21)에는 폼 만들기와 공유까지만 하고, 정리·검토는 시험 뒤로 미뤄도 일정에 지장 없습니다.
