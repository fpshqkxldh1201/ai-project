# 라벨 정의서 (v2)

Lumi가 실제로 가진 기능(Function Calling + 일반 대화)에 맞춰 9개 라벨로 나눕니다.
한 문장에는 **라벨 하나**만 붙입니다.

| 라벨 | 뜻 | 연결되는 Lumi 기능 | 예시 |
|---|---|---|---|
| `schedule_add` | 일정(약속·수업·회의·행사)을 새로 등록 | `add_schedule` | 내일 3시에 팀 회의 잡아줘 |
| `schedule_get` | 등록된 일정을 조회·겹침 확인 | `get_schedules` | 오늘 일정 뭐 있어? |
| `reminder_add` | 정해진 시점에 알려 달라는 요청 | `add_reminder` | 30분 뒤에 빨래 돌리라고 알려줘 |
| `reminder_get` | 걸어 둔 알림·할 일 조회 | `get_reminders` | 리마인더 뭐 남았어? |
| `note_save` | 나에 대한 사실·선호를 기억해 달라 | `save_note` | 나 오이 싫어해 기억해줘 |
| `note_delete` | 저장된 기억·노트를 지워 달라 | `delete_note` | 아까 저장한 노트 지워줘 |
| `search_web` | 사실·최신 정보를 검색해 달라 | `web_search` / `google_search` | 환율 지금 얼마야 |
| `search_video` | 영상·음악 찾기/재생 | `youtube_search` | 로파이 음악 틀어줘 |
| `chat_emotion` | 인사·잡담·감정 표현·기능 문의 (도구 호출 없음) | (대화만) | 오늘 너무 힘들었어 |

## 애매할 때 쓰는 규칙

1. **행동 단서가 우선**: 일정/약속/회의/캘린더 → `schedule_*`, 알림/알려줘/리마인드/할 일 → `reminder_*`, 기억/메모/노트/잊어 → `note_*`, 검색/찾아/시세/뉴스 → `search_web`, 유튜브/영상/틀어/플레이리스트 → `search_video`.
2. **등록 vs 조회**: 새로 만들어 달라는 말이면 `*_add`/`note_save`, 이미 있는 것을 묻는 말이면 `*_get`.
3. **일정 vs 알림**: 시간과 함께 만남·행사를 "잡아/등록/넣어"라고 하면 `schedule_add`, 시간과 함께 행동을 "알려줘/깨워줘"라고 하면 `reminder_add`.
4. **노트 vs 알림**: 시간이 지나도 유효한 사실·선호는 `note_save`, 특정 시점에 울려야 하면 `reminder_add`. (예: "나 다음 주에 시험 있다는 거 기억해줘"는 알림을 요구하지 않으므로 `note_save`)
5. **영상·음악 vs 검색**: 재생·시청·추천 음악 → `search_video`, 정보·사실 확인 → `search_web`.
6. **도구 단어가 나와도 요청이 아니면 `chat_emotion`**: "일정이 너무 많아서 스트레스야", "유튜브 보다가 밤샜어"는 하소연이지 요청이 아닙니다.
7. **의도가 둘 섞였으면 주된 행동(문장에서 먼저 요구한 것) 하나**를 고르고, `hard`를 1로 표시합니다.
8. **지시어**("그거 잊어줘", "방금 말한 거 잊어줘")는 `note_delete`입니다.
9. **날씨·시세·스포츠 결과**처럼 Lumi에 전용 도구가 없는 최신 정보는 모두 `search_web`입니다.

## `hard` 열
경계가 애매한 문장은 1, 아니면 0. 평가할 때 "어려운 문장에서 얼마나 틀리는지"를 따로 볼 수 있습니다.

## 이 데이터에 대해 (발표 때 밝힐 것)
- 문장 초안은 AI(Claude)가 작성했고, 사람이 하나씩 검수·수정한 것입니다.
- 실제 사용자 대화는 개인정보 보호 설계(저장 안 함) 때문에 수집하지 않았습니다.
- v1.1: 첫 신경망 실험(검증셋 오분류 4건)에서 드러난 약점 — 일정↔알림, 저장↔삭제(부정형 "잊지 마", `forget`) — 에 맞춰 문장 40개(id 291~330)를 추가했습니다. 오분류된 검증 문장은 복사하지 않고 소재·표현을 바꿔서 썼습니다. 데이터가 바뀌어 train/val/test를 다시 나눴으므로 v1 숫자와 직접 비교하지 않습니다.
- 한국어 약 70%, 영어 약 30%. 일본어·중국어·스페인어는 이번 범위에서 제외했습니다.
- v2: 문장 277개(id 331~607)를 추가해 총 607문장이 되었고, `source`(ai/peer/self)·`version`(v1/v1.1/v2) 열이 생겼습니다. 테스트셋 v1(49문장)은 **동결**(`data/splits/test_v1_frozen.csv`)해 더 이상 바꾸지 않고, 나머지를 학습/검증(85/15)으로 다시 나눴습니다. 새 검증셋(85문장)은 v1 검증셋과 달라서 숫자를 직접 비교하지 않습니다.

## 범위 밖(OOS)과 모호(AMB) — v2 평가용 정의
분류기는 9개 라벨만 압니다. 그 밖의 말을 억지로 9개 중 하나로 보내면 Lumi가 엉뚱한 도구를 부르게 되므로, 평가 때 아래 세 가지를 따로 셉니다.

**OOS = Lumi에 대응 도구가 없는 "행동 요청"** (현재 도구: 일정 조회·등록, 알림 조회·등록, 노트 저장·삭제, 웹/구글/유튜브 검색)

| 범주 | 뜻 | 예시 |
|---|---|---|
| O1 발신·연락 | 문자·전화·메일·DM을 대신 보내기 | 엄마한테 문자 보내줘 |
| O2 기기·재생 제어 | 스마트홈·기기·영상/음악 재생 조작 | 거실 불 꺼줘, 영상 일시정지 |
| O3 결제·주문·예약 | 돈이 오가거나 외부 예약이 필요한 일 | 치킨 시켜줘, 치과 예약해줘 |
| O4 파일·시스템 | 파일·폴더·앱 조작, 내보내기 | 바탕화면 정리해줘 |
| O5 기존 일정·알림 수정·삭제 *(near)* | 이미 있는 일정·알림을 고치거나 지움 (현재는 조회·등록만 가능) | 금요일 약속 취소해줘 |
| O6 조건·이벤트 자동화 *(near)* | "~하면 알려줘"처럼 외부 사건을 감시 | 비 오면 우산 챙기라고 알려줘 |
| O7 계정·설정 | 비밀번호·언어·구독·앱 설정 변경 | 다크 모드로 바꿔줘 |

*near*는 일정·알림·노트 단어가 섞여 있어 9개 의도와 헷갈리기 쉬운 문장입니다(OOS 중 가장 어려운 부분).

**OOS가 아닌 것**
- 사실·최신 정보 질문(날씨, 시세, 스포츠 결과, "수도가 어디야") → `search_web` (규칙 9)
- 기능 문의·인사·감정·잡담 → `chat_emotion`
- 번역·요약·글쓰기처럼 Gemini가 도구 없이 대답하는 일 → `chat_emotion`
- 유해·탈옥·프롬프트 인젝션 → 의도 분류가 아니라 기존 보안 계층이 담당

**AMB(모호)** — 두 가지 이상으로 읽히거나 정보가 모자라 되묻는 게 맞는 문장. 정답 라벨 대신 `expected_decision=clarify`.
예: "그거 해줘", "내일 거 알려줘"(일정? 알림?), "엄마한테 전화하라고 알려주고 문자도 보내줘"(복합).
- 주된 행동이 분명한 복합 문장은 규칙 7(먼저 요구한 것 하나)로 라벨을 붙이고 `hard=1`. 분명하지 않을 때만 AMB.

**평가 때 쓰는 결정값**: `answer`(의도 하나로 처리), `reject`(OOS → "아직 못 해요" 안내), `clarify`(AMB → 되묻기).
